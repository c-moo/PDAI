# 2D GODOT peli  

## Pelin idea
Pelin ideaa ei ole kiveenhakattu (vielä), muutakuin että se on lineaarinen 2D platformer jonka ideana on päästä kentän loppuun siirtyäkseen seuraavaan.

## Pelin ominaisuuksia
 Pelistä löytyy
 - vihollisia
 - parkouria
 - muutama kenttä
 - wall-jump mekaniikka
 - kerättävät esineet

## Assetit
Pelissä käytetyt assetit on otettu sivuilta kuten "itch.io" ja "opengameart.org"
